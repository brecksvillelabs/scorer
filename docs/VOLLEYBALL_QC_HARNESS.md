# Volleyball Round-Robin QC Harness\n\nVolleyball is the reference implementation for the Scorer multi-sport QC harness.\n\n## What the harness creates\n\n- QC persona: `Volleyball QC Operator`\n- Three persistent saved teams: Lake Erie Lightning, Cleveland Comets, and Brecksville Blaze\n- A deterministic 12-player roster for every team\n- A generated SVG team logo for every team, loaded through Scorer's real file-input/logo path\n- Six ordered round-robin matches: A→B, B→A, B→C, C→B, C→A, A→C\n\nEvery match reloads the teams from Scorer's saved-team storage before starting. The harness asserts the reloaded name, logo, and complete roster.\n\n## Match exercise\n\nEach ordered match is played to a deterministic 3-0 final: Set 1 25-18, Set 2 25-20, Set 3 25-22. The first match pauses at 7-5 for a live-game screenshot. Every match validates packaged game state, both logos, both 12-player rosters, final result, full scoreboard team names, and Share Score availability.\n\n## Screenshots\n\nA successful run produces exactly eight PNGs plus `volleyball-qc-report.csv`:\n\n1. `01-volleyball-team-setup.png`\n2. `02-volleyball-live-7-5.png`\n3. `03-volleyball-final-scoreboard.png`\n4. `04-volleyball-b-vs-a-final.png`\n5. `05-volleyball-b-vs-c-final.png`\n6. `06-volleyball-c-vs-b-final.png`\n7. `07-volleyball-c-vs-a-final.png`\n8. `08-volleyball-a-vs-c-final.png`\n\n## Run on the local Android emulator\n\nFrom the repository root in PowerShell:\n\n```powershell\n.\\tools\\run-volleyball-qc.ps1\n```\n\nOr use `-SkipSync` if native assets are already synced. The runner targets only `com.brecksvillelabs.scorer.VolleyballRoundRobinQcTest` and pulls artifacts to `android\\qc-output\\<timestamp>-volleyball\\`.\n\nUse a dedicated QC emulator. The harness only removes prior fixtures with these three QC team names and the Volleyball QC persona, but it does replace the current active Scorer match while testing.\n\n## Expansion rule\n\nReuse `RoundRobinQcSupport` for the next sport. Add only the sport-specific fixture, scoring exercise, assertions, and visual checkpoints rather than copying the whole Volleyball driver.\n

## Start-transition gate

Before any point can be scored, the harness now verifies that the match setup modal is fully dismissed: native `hidden` state is set, the `hidden` class is present, `aria-hidden="true"`, computed display is `none`, and the live scoreboard visibly contains both saved team names and both team logos. The first game records a dedicated post-start screenshot before scoring begins.
