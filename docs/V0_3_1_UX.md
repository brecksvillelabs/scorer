# v0.3.1 UX decisions

- Home is a safe navigation action: leaving the scoreboard never deletes an active match.
- Home exposes Resume live game when an unfinished match exists.
- Automatic sport completion owns the normal final state.
- Manual End Game is secondary and confirmed, intended for forfeit/time-limit/abandoned/other real-world endings.
- Undo remains available after automatic completion and reopens the match when the match-ending scoring action is undone.
- Final presentation emphasizes winner/result and routes to Game Journal, Home and New Match instead of encouraging further scoring.
