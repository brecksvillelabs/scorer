# v0.3.1 acceptance criteria

1. Best-of-3 volleyball finalizes at 2–0 and 2–1.
2. Best-of-5 volleyball remains live at 2–0.
3. Finalized match cannot accept ordinary score increments.
4. Undo of an automatic match-winning action restores the previous active state.
5. Home navigation preserves the active match and offers Resume.
6. Manual End Game requires confirmation and records a reason.
7. Final screen offers Journal, Home and New Match.
8. Existing tennis, badminton, cricket, basketball, soccer and football regressions remain green.
